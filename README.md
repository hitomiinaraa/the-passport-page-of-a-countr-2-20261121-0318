An invented passport spread for the Republic of Caelum, a mountain observatory republic: a data page with a vector portrait and a TD3 machine-readable zone, and a visa page with eight entry/exit stamps and a summit-zone condition box. Every date is internally consistent — all stamps fall after issue (12 JUN 2023) and before expiry (11 JUN 2033), every entry precedes its exit, and the MRZ check digits are computed per ICAO 7-3-1.

## Run it

```sh
node main.ts
```

Writes `/output/entry.png` (1024x1024, deterministic, no network).
